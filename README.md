# Portal Espace Cristallins

Website estático desenvolvido com HTML5 semântico, CSS3 e JavaScript Vanilla.

## Executar localmente

É necessário Node.js 18 ou superior.

```bash
npm run dev
```

Abrir http://localhost:3000 no navegador.

## Publicar no GitHub Pages

O GitHub Pages publica os ficheiros estáticos diretamente. O servidor `server.mjs` serve apenas para desenvolvimento local e não é executado no GitHub Pages.

1. Criar um repositório no GitHub e enviar o conteúdo desta pasta.
2. Em **Settings → Pages**, escolher a branch principal e a pasta `/ (root)`.
3. Guardar e aguardar a publicação.

O `index.html` está na raiz do projeto.
